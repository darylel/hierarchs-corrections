# Orthodox Hierarchs: corrections

Report errors and gaps in the data of [Orthodox Hierarchs](https://hierarchs.zosha.net):
a wrong date, a missing or wrong consecrator, a see held, a duplicate record, a
hierarch who is missing.

Use the **Suggest a correction** link at the foot of a hierarch's page, or
[open an issue](https://github.com/darylel/hierarchs-corrections/issues/new?template=correction.yml).
Please give a source for the correction: a link (Wikipedia, a church's site, a
directory) or a citation of a printed work.

The data is published under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/);
it can be downloaded from [the site's About page](https://hierarchs.zosha.net/about/#download).
